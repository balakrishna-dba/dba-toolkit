For running services:

Get-Service | Where-Object { $_.Status -eq 'Running' }

Export to CSV:
Get-Service | Where-Object { $_.Status -eq 'Stopped' } | Export-Csv C:\temp\stopped_services.csv -NoTypeInformation

Export to Text:
Get-Service | Where-Object { $_.Status -eq 'Stopped' } | Out-File C:\temp\stopped_services.txt

Get-Service | Where-Object { $_.DisplayName -like "*SQL*" -and $_.Status -eq "Stopped" } | Select-Object Name, DisplayName, Status

Simple program to know the exact drive free space:
****************************************************
$cDrive = Get-PSDrive -Name C
$freeGB = [math]::Round($cDrive.Free / 1GB, 2)
"Drive C has $freeGB GB free"
*******************************************************

Use foreach:
*******************************************************

$drives = Get-PSDrive -PSProvider FileSystem

foreach ($drive in $drives) {
    $free = [math]::Round($drive.Free / 1GB, 2)
    if ($free -lt 20) {
        Write-Host "WARNING: Drive $($drive.Name) only has $free GB free!" -ForegroundColor Red
    } else {
        Write-Host "OK: Drive $($drive.Name) has $free GB free." -ForegroundColor Green
    }
}

To check multiple services present or not
************************************************************************

foreach ($name in $sqlServices) {
    $svc = Get-Service -Name $name -ErrorAction SilentlyContinue

    if ($null -eq $svc) {
        Write-Host "$name -> Not installed on this machine" -ForegroundColor Yellow
    } elseif ($svc.Status -eq "Running") {
        Write-Host "$name -> Healthy (Running)" -ForegroundColor Green
    } else {
        Write-Host "$name -> Attention ($($svc.Status))" -ForegroundColor Red
    }
}
